# 統計検定2級 記述ドリル

AI（Claude）が統計検定2級の問題を作り、解き方を文章で書くと AI が赤ペンで採点する練習ページ。

- 公開ページ: https://claude.ai/artifact/Ek2Lr31wQktdbDGKegEs12 （claude.ai にログインして開く）
- 「苦手を優先」にすると、2026-11-10〜12 の振り返りで要復習だった分野（カイ二乗検定・単回帰・F検定・ポアソン・重回帰・正規分布）が多めに出る。採点の点数が低い分野ほど、さらに出やすくなる。
- 正しい式とその意味（何を代入し、何を判断するか）が書けていれば、数値を最後まで計算していなくても○になる。
- 採点では、過去と同じ間違い（期待度数を全セル同じにする、など）が再発していないかも見る。
- 採点結果はページのデータベース（`attempts` コレクション）に残る。Claude に「ドリルの履歴を見て振り返りを更新して」と頼めば読み出せる。
- AI の呼び出しは開いた人の Claude の利用枠を使う。
