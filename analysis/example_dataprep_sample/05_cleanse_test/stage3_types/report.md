# クレンジング 段階3: 型の変換

**役割**: 各列の種類を決め、数値（¥ , % を外す）・真偽（はい/いいえ→1/0）・日時に変換する。読めなかった値は欠損にして一覧にする

- 入力: analysis/example_dataprep_sample/05_cleanse_test/stage2_text/data.csv
- 出力: analysis/example_dataprep_sample/05_cleanse_test/stage3_types/data.csv
- 行 × 列: 115 × 14 → 115 × 14
- 欠損セル: 61 → 62
- 作成日時: 2026-11-12 08:50
