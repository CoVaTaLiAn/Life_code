## 8. おすすめのエンコーディング

| 列 | 種類 | 方法 | 理由 | 代わりの案 |
|---|---|---|---|---|
| 顧客ID | ID | 使わない（除外） (`drop`) | 行を識別するだけの値。学習に使うと丸暗記になる | 別の表との結合キーとして使う |
| 年齢 | 数値 | そのまま (`passthrough`) | 分布に大きな偏りがない。木のモデルならそのまま使える | 線形モデル・ニューラルネットなら standard（標準化） |
| 性別 | カテゴリ | 0/1 化 (`binary`) | 値が2種類。0/1 にすれば十分 | - |
| 都道府県 | カテゴリ | ターゲット(目的変数の平均) (`target`) | 15 種類。One-Hot では列が増えすぎるので目的変数の平均に置き換える（fold 外で計算） | frequency ／ onehot（上位だけ残す） |
| 郵便番号 | ID | 使わない（除外） (`drop`) | 行を識別するだけの値。学習に使うと丸暗記になる | 別の表との結合キーとして使う |
| プラン | カテゴリ | One-Hot (`onehot`) | 3 種類と少ない。列が増えすぎず、順序の仮定も置かない | 木のモデルだけなら label |
| 会員ランク | カテゴリ | 順序(整数) (`ordinal`) | 値に順序がある。順番どおりの整数にする | onehot |
| 年収 | 数値 | 対数変換 log1p (`log1p`) | 右に裾が長い（歪度 1.3、0 以上）。対数で裾を縮める | 木のモデル（LightGBM など）だけなら passthrough でよい |
| 月間来店回数 | 数値 | そのまま (`passthrough`) | 分布に大きな偏りがない。木のモデルならそのまま使える | 線形モデル・ニューラルネットなら standard（標準化） |
| 平均滞在分 | 数値 | 対数変換 log1p (`log1p`) | 右に裾が長い（歪度 1.2、0 以上）。対数で裾を縮める | 木のモデル（LightGBM など）だけなら passthrough でよい |
| 登録日 | 日時 | 日時の分解＋周期 (`datetime`) | 年・月・曜日などに分解し、月と曜日は sin/cos で周期を表す | 基準日からの経過日数だけ使う |
| メール受信 | 真偽(0/1) | 0/1 化 (`binary`) | 値が2種類。0/1 にすれば十分 | - |
| 割引率 | 数値 | そのまま (`passthrough`) | 数値だが 4 種類しかない。大小に意味があればそのまま | コード値（大小に意味がない）なら onehot |
| コメント | カテゴリ | One-Hot (`onehot`) | 4 種類と少ない。列が増えすぎず、順序の仮定も置かない | 木のモデルだけなら label |
| 解約 | 数値 | 目的変数: クラス→整数 (`target_label`) | 目的変数（2 クラスの分類）。クラスを整数にする | - |
