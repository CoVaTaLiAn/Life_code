# マッスルパンダ

筋トレを記録するとパンダが育つ、ブラウザだけで動く記録アプリです。
インストール不要。`index.html` をブラウザで開くだけで使えます（スマホ対応）。

## 使い方
1. 「LOG」タブで部位・種目・重量・回数・セット数（有酸素は時間）を入力して保存
   - 「リストに追加」で複数の種目を貯めて「まとめて記録」で一括保存できます
   - 「前回のメニューを読み込む」で前回のトレーニング内容をリストに入れられます
2. 記録するたびに XP がたまり、パンダがレベルアップ・進化します
3. 「履歴」タブで過去の記録と12週間のカレンダーを確認できます

## 育成ルール
| 項目 | 内容 |
|---|---|
| XP | 回数×セット数×重量で計算。有酸素は時間で計算 |
| 連続ボーナス | 毎日続けると1日ごとに +10%（最大 +50%） |
| 進化 | パンダのたまご → こパンダ(Lv3) → わんぱく(Lv6) → マッチョ(Lv11) → ゴリマッチョ(Lv20) → レジェンド(Lv35) |
| 見た目 | 胸・肩を鍛えると肩幅と胸筋、腕で力こぶ、腹で腹筋、脚で脚の太さが育つ。段階ごとにハチマキ・リストバンド・王冠・笹が付く |
| きげん | トレーニングをサボるとしょんぼり → ぐったりに |

## データについて
- 記録はブラウザ内（localStorage）に保存されます。サーバーには送信しません
- ブラウザのデータを消すと記録も消えるので、「履歴」タブの「バックアップを保存」でJSONを保存しておくと安心です
