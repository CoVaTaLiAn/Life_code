# マッスルモンスター

筋トレを記録するとモンスターが育つ、ブラウザだけで動く記録アプリです。
インストール不要。`index.html` をブラウザで開くだけで使えます（スマホ対応）。

## 使い方
1. 「LOG」タブで部位・種目・回数（プランクなどは秒数）・セット数を入力して保存（有酸素は時間）
   - 種目は自重トレーニング中心。種目を選ぶと、目安・難易度・やり方・ポイントが見られます
   - 加重したいときだけ「加重(kg)」を入力
   - 「リストに追加」で複数の種目を貯めて「まとめて記録」で一括保存できます
   - 「前回のメニューを読み込む」で前回のトレーニング内容をリストに入れられます
2. 記録するたびに XP がたまり、モンスターがレベルアップ・進化します（ウルフ／フランケン／ウーパーから選べます。育ち具合は共通。キャラはドット絵で表示）
3. 「DATA」タブで記録を表（データベース）で見たり、グラフで可視化できます
   - XPの推移（30日・12週・累計）、部位別の割合、週ごとの総回数、種目別の伸び（1セットの最高回数・合計回数／秒数）
   - 表は部位・種目で絞り込み、列名で並べ替え、CSVでコピーできます
4. 「HISTORY」タブで日ごとの記録と12週間のカレンダーを確認できます

## 育成ルール
| 項目 | 内容 |
|---|---|
| XP | 回数×セット数で計算（秒数の種目は3秒＝1回、加重するとボーナス）。有酸素は時間で計算 |
| 連続ボーナス | 毎日続けると1日ごとに +10%（最大 +50%） |
| 進化 | たまご → ちび(Lv3) → わんぱく(Lv6) → マッチョ(Lv11) → ゴリマッチョ(Lv20) → レジェンド(Lv35) |
| 見た目 | 胸・肩を鍛えると肩幅と胸筋、腕で力こぶ、腹で腹筋、脚で脚の太さが育つ。段階ごとにハチマキ・リストバンド・王冠と、キャラごとのレジェンドアイテムが付く |
| きげん | トレーニングをサボるとしょんぼり → ぐったりに |

## データについて
- 記録はブラウザ内（localStorage）に保存されます。サーバーには送信しません
- ブラウザのデータを消すと記録も消えるので、「履歴」タブの「バックアップを保存」でJSONを保存しておくと安心です
