# Gmail 自動振り分け（GAS）

1時間ごとに未読メールをルールで振り分け、毎朝7時に要約メールを自分宛てに送る。
AIを使わないので、Claude のトークンはかからない（Google の無料枠で動く）。

## 振り分けルール

| ラベル | 条件 | 処理 |
|---|---|---|
| 転職/注目 | 転職サイトから届き、注目キーワード（データサイエンティスト、医療、公募など）を含む | 未読のまま受信箱に残す |
| 転職/その他 | 転職サイトから届いた上記以外 | 既読・アーカイブ |
| 広告 | Audible・Amazon・Xmind などの送信元 | 既読・アーカイブ |
| 通知 | OpenAI のタスク通知、Anthropic の領収書 | 既読（受信箱に残す） |
| 要確認 | 件名に Security alert・ログイン・new device など | 未読のまま、要約で知らせる |
| （なし） | どれにも当たらない | 触らない |

ルールは `Code.gs` 冒頭の `CONFIG` を書き換えれば変えられる。

## 設置手順（5分）

1. https://script.google.com を開き「新しいプロジェクト」
2. 最初からある `コード.gs` の中身を消し、`Code.gs` の内容を貼り付けて保存
3. 上部の関数選択で `setup` を選び「実行」
4. 権限の確認画面で Google アカウントを選び「詳細」→「（安全ではないページ）に移動」→「許可」
   （自分で作ったスクリプトなので表示される警告。Gmail の読み書きとメール送信の権限を求める）

これで、1時間ごとの振り分けと毎朝7時の要約が自動で動く。止めるときは左メニューの「トリガー」から削除する。

## 要約メールの例

```
件名: [Gmail要約] 10/30 注目3件

【転職/注目】3件
- 【面談確約】希望条件にマッチした新着スカウト（ビズリーチ）
  https://mail.google.com/mail/u/0/#all/...

【要確認】1件
- Security alert（Google）

【自動処理】
- 転職/その他：18件（既読・アーカイブ）
- 広告：4件（既読・アーカイブ）
- 通知：6件（既読）
- 未分類：2件（受信箱に残したまま）
```
