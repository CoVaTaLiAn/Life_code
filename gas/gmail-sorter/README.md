# Gmail 自動振り分け（GAS）

1時間ごとに未読メールを振り分け、毎朝7時に要約メールを自分宛てに送る。
トークン（費用）を使うのは「迷ったメール」だけになるよう、4段階で判定する。

```
新着メール
  │
  ├─ 1. ルール（GAS・無料）……… 送信元・キーワード・あなたが過去に決めた送信元
  │      明らかなスパム → 迷惑メールへ／関係ないお知らせ → 既読 など
  │
  ├─ 2. 確率（ルールに当たらないものだけ）
  │      Jev（TYPESAFE_API_KEY があるとき）か、過去の判定から学ぶ簡易計算（無料）で
  │      「スパム確率」「既読でよい確率」を出す。95%以上ならそのまま処理
  │
  ├─ 3. Claude（Claude Code で頼んだときだけ）
  │      シート「判断待ち」の行（差出人・件名・冒頭100字・確率）だけを見て提案を書く
  │
  └─ 4. あなたが決める → GAS が1時間以内に処理し、その送信元を覚える（次からは 1 で自動）
```

判定結果は、ルール・Jev・簡易計算・あなたのどれで決まったかも含めて、すべてスプレッドシート「Gmail振り分けログ」に残る。

## 迷ったメールの片付け方

1. Claude Code（このリポジトリ）で「**Gmailの判断待ちを見て**」と頼む
   → Claude がシート「判断待ち」に提案を書き、一覧を見せる（手順：`.claude/skills/gmail-triage/SKILL.md`）
2. 「全部OK」「3は残す」のように答える → Claude が「あなたの判断」列に書く
3. 1時間以内に GAS が処理し、同じ送信元は次から自動でそのカテゴリになる

Claude を使わずに決めてもよい：

- シート「判断待ち」の「あなたの判断」列（選択式）で選ぶ
- Gmail でメールを開き「ラベルを変更」でカテゴリのラベルを付ける（「要判断」は外さなくてよい）

覚えた送信元は、スクリプト プロパティの `LEARNED` に入っている。消せば忘れる。

## カテゴリ

| ラベル | 処理 | 主な判定元 |
|---|---|---|
| 転職/注目 | 未読のまま受信箱に残す | ルール（転職サイト＋注目キーワード） |
| 転職/その他 | 既読・アーカイブ | ルール |
| 広告 | 既読・アーカイブ | ルール（`adSenders`） |
| 通知 | 既読（受信箱に残す） | ルール（`noticeSenders`・件名の `noticeKeywords`）／確率 |
| （迷惑メール） | 既読にして Gmail の迷惑メールへ（30日で自動削除） | ルール（`spamKeywords`・`spamSenders`）／確率 |
| （削除） | 既読にしてゴミ箱へ（30日で完全削除） | ルール（`trashSenders`：Contract One など） |
| 要確認 | 未読のまま、要約で知らせる | ルール（件名に Security alert など） |
| 要返信 | 未読のまま、要約で知らせる | あなた |
| 残す | 未読のまま受信箱に残す | あなた |
| 要判断 | 未読のまま、シート「判断待ち」に載せて要約で聞く | 確率が95%未満のとき |

ルールは `Code.gs` 冒頭の `CONFIG` を書き換えれば変えられる。間違って迷惑メールに入ったら、Gmail で「迷惑メールではない」を押し、シートか Gmail のラベルで正しいカテゴリを教える。

## 確率の出し方

- **Jev**（TypeSafe AI の判断専用モデル）：スクリプト プロパティに `TYPESAFE_API_KEY` を登録したときだけ使う。1回の実行で最大20件
  - 呼び出し先・モデル名は `CONFIG.jev`。Jev の返答の形は公式資料で確認できていないため、
    登録したら GAS エディタで `testJev` を実行し、実行ログに「OK」と確率が出るか確かめる。
    読めないときは自動で簡易計算に切り替わる（実行ログに返答が出るので、それを Claude に見せて直す）
- **簡易計算**（キーなしでも動く・無料）：判定ログのうち「ルール」と「あなた」が決めた行から、送信元と件名の言葉で学ぶ
  - 各グループの学習例が10件（`CONFIG.prob.minExamples`）たまるまでは自動処理せず、確率を参考に出すだけ
  - 迷惑メールへの自動移動は、過去にスパムだった送信ドメインに限る（確率が極端に出やすいため）

## 設置手順

1. https://script.google.com を開き「新しいプロジェクト」
2. 最初からある `コード.gs` の中身を消し、`Code.gs` の内容を貼り付けて保存
   （GitHub からの自動反映を設定済みなら不要。手順：`../SETUP_PC.md`）
3. Jev を使う場合：左メニューの「プロジェクトの設定」→「スクリプト プロパティ」→「プロパティを追加」
   - プロパティ：`TYPESAFE_API_KEY`
   - 値：TypeSafe AI で発行した API キー
4. 上部の関数選択で `setup` を選び「実行」
5. 権限の確認画面で「詳細」→「（安全ではないページ）に移動」→「許可」
   （自分で作ったスクリプトなので出る警告。Gmail・スプレッドシート・外部API呼び出しの権限を求める）

止めるときは左メニューの「トリガー」から削除する。

## 費用の目安

- ルール・簡易計算：無料
- Jev：ルールに当たらないメールだけ（今の受信箱なら1日数件）。料金は TypeSafe AI の料金表を確認
- Claude：Claude Code で頼んだときだけ。シートの短い行だけを読むので、1回あたりのトークンは少ない

以前の Claude API による自動判定（`ANTHROPIC_API_KEY`）は、この仕組みに置き換えたため使わない。
