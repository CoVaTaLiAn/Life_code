# Gmail 自動振り分け（GAS）

1時間ごとに未読メールを振り分け、毎朝7時に要約メールを自分宛てに送る。

- まずルール（送信元・キーワード）で判定する。ここは無料で、AIを使わない。
- ルールに当たらないメールだけ Claude API に判定させる。
- 判定結果は、ルール・AIともにすべてスプレッドシート「Gmail振り分けログ」に残す（日時・判定者・カテゴリ・AIの理由・差出人・件名・リンク）。

## カテゴリ

| ラベル | 処理 | 主な判定元 |
|---|---|---|
| 転職/注目 | 未読のまま受信箱に残す | ルール（転職サイト＋注目キーワード）／AI |
| 転職/その他 | 既読・アーカイブ | ルール／AI |
| 広告 | 既読・アーカイブ | ルール／AI |
| 通知 | 既読（受信箱に残す） | ルール／AI |
| 要確認 | 未読のまま、要約で知らせる | ルール（件名に Security alert など）／AI |
| 要返信 | 未読のまま、要約で知らせる | AI |
| 残す | 未読のまま受信箱に残す | AI |

ルールは `Code.gs` 冒頭の `CONFIG` を書き換えれば変えられる。

## 設置手順

1. https://script.google.com を開き「新しいプロジェクト」
2. 最初からある `コード.gs` の中身を消し、`Code.gs` の内容を貼り付けて保存
3. AI判定を使う場合：左メニューの「プロジェクトの設定」→「スクリプト プロパティ」→「プロパティを追加」
   - プロパティ：`ANTHROPIC_API_KEY`
   - 値：https://platform.claude.com で発行した API キー
   （未設定ならルールだけで動き、当たらないメールは触らない）
4. 上部の関数選択で `setup` を選び「実行」
5. 権限の確認画面で「詳細」→「（安全ではないページ）に移動」→「許可」
   （自分で作ったスクリプトなので出る警告。Gmail・スプレッドシート・外部API呼び出しの権限を求める）

止めるときは左メニューの「トリガー」から削除する。

## AIの費用の目安

AIに回るのはルールに当たらないメールだけ（今の受信箱なら1日数件）。1回の実行で最大20件まで。

| モデル（`CONFIG.ai.model`） | 1通あたり | 1日5通で1か月 |
|---|---|---|
| `claude-opus-5-5`（初期値） | 約1円 | 約150円 |
| `claude-haiku-5-5` | 約0.03円 | 約5円 |

概算。判定の質は Opus のほうが上。費用を最小にしたいなら Haiku に変える。
