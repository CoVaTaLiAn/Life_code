# 期限カレンダー

> 一般的な目安（2026年10月時点の制度）。設立日・決算月が決まったら総務・法務部が具体的な日付に直す。
> 実際の提出前に、国税庁・自治体・日本年金機構の最新情報と税理士で確認すること。

## 設立直後

| 期限 | 提出先 | 内容 |
|---|---|---|
| 設立から5日以内 | 年金事務所 | 健康保険・厚生年金の新規適用届（役員報酬を払う社長1人でも加入） |
| 設立から1か月以内 | 税務署 | 給与支払事務所等の開設届出書 |
| 設立から2か月以内 | 税務署 | 法人設立届出書（定款の写しなどを添付） |
| 自治体の定める日まで（多くは1〜2か月以内） | 都道府県・市区町村 | 法人設立届（東京23区は都税事務所のみ） |
| 設立から3か月以内 か 最初の事業年度末の早いほう | 税務署 | 青色申告の承認申請書（赤字の繰越などのため必須） |
| 随時（出せば翌月から適用） | 税務署 | 源泉所得税の納期の特例の承認申請（納付が年2回になる） |
| 事業年度開始から3か月以内 | ― | 役員報酬の額を決めて記録する（議事録・決定書） |
| 必要に応じて | 税務署 | インボイス（適格請求書発行事業者）の登録申請 |

## 毎月

| 期限 | 内容 |
|---|---|
| 毎月末ごろ | 翌月の社会保険料が口座から引き落とし（前月分） |
| 翌月10日 | 源泉所得税の納付（納期の特例を受けていない場合） |
| 月初〜5営業日 | 月次締め（`monthly-close`） |

## 毎年

| 期限 | 内容 |
|---|---|
| 1月20日 | 源泉所得税の納付（納期の特例：7〜12月分） |
| 1月31日 | 法定調書合計表・給与支払報告書・償却資産申告 |
| 7月1日〜10日 | 社会保険の算定基礎届 |
| 7月10日 | 源泉所得税の納付（納期の特例：1〜6月分） |
| 12月 | 年末調整（社長自身の分） |
| 決算日から2か月以内 | 法人税・地方法人税・法人住民税・事業税の申告と納付（消費税の課税事業者なら消費税も） |
| 決算日から3か月以内 | 定時株主総会・社員総会（株式会社は決算公告も） |
| 毎年 | 法人住民税の均等割は赤字でもかかる（多くの地域で年7万円程度） |

## 数年ごと

| いつ | 内容 |
|---|---|
| 役員の任期満了時（株式会社のみ。非公開会社は最長10年） | 役員の重任登記（怠ると過料） |
| 設立から3期目の前 | 消費税の課税事業者になるかの判定（2期前の売上が1,000万円超など） |
