# 期限のしくみ

具体的な日付は `./solo deadlines --save` で自動計算し、`deadlines-calendar.md` に書き出す。
設立日・決算月・会社の形などは `company/config.toml` から読む。

> 一般的なルール（2026年10月時点）による目安。提出前に国税庁・自治体・日本年金機構の最新情報と税理士で確認すること。
> 国税の期限が土日・祝日・12/29〜1/3に当たるときは、翌営業日にずらして表示している。

## 何が入っているか

| 時期 | 内容 | 提出先 |
|---|---|---|
| 設立から5日以内 | 健康保険・厚生年金の新規適用届（社長1人でも加入） | 年金事務所 |
| 自治体ごと（東京都は15日以内、多くは1〜2か月以内） | 法人設立届（地方税） | 都道府県・市区町村 |
| 設立から1か月以内 | 給与支払事務所等の開設届出書 | 税務署 |
| 設立から2か月以内 | 法人設立届出書 | 税務署 |
| 設立から3か月を経過した日と1期目の末日の早いほうの前日 | 青色申告の承認申請書 | 税務署 |
| 期首から3か月以内 | 役員報酬の決定（議事録） | 社内 |
| 1期目の末日まで | インボイス登録の検討（免税事業者が設立時から登録する場合） | 税務署 |
| 毎年 1/20・7/10 | 源泉所得税の納付（納期の特例を受けている場合。受けていなければ毎月10日） | 税務署・金融機関 |
| 毎年 1/31 | 法定調書合計表、給与支払報告書、償却資産申告 | 税務署・市区町村 |
| 毎年 7/1〜7/10 | 社会保険の算定基礎届 | 年金事務所 |
| 決算日から2か月以内 | 法人税・住民税・事業税（課税事業者なら消費税も）の申告・納付 | 税務署・都道府県・市区町村 |
| 申告の前 | 定時総会で決算を承認（株式会社は決算公告も） | 社内 |
| 決算日から約8か月後 | 中間申告（前期の法人税額が一定以上の場合） | 税務署 |
| 任期満了時（株式会社） | 役員の重任登記（非公開会社は任期最長10年） | 法務局 |

## ツールに入っていないもの（自分で確認する）

- 消費税の課税事業者になる判定（2期前の売上、特定期間の売上と給与）— 税理士に確認
- 自治体独自の届出や期限
- 許認可が必要な事業の届出・更新
- 労働保険（従業員を雇ったとき）
