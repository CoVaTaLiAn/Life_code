# 契約書チェックリスト

総務・法務部が契約書を確認するときに使う。結果は「条項 / 問題 / 修正案 / 理由」の表で返す。

## 必ず見る項目

- [ ] **当事者**：会社名・代表者が正しいか（個人名で結んでいないか）
- [ ] **業務の範囲**：何をやって、何をやらないかがはっきりしているか
- [ ] **報酬と支払**：金額、税込か税抜か、支払日（下請法・フリーランス新法の対象なら受領から60日以内）
- [ ] **検収**：検収の期間と、期間を過ぎたら合格とみなす定め
- [ ] **知的財産**：成果物の権利がいつ・どこまで移るか。自分のノウハウや汎用部品が残るか
- [ ] **秘密保持**：範囲と期間
- [ ] **損害賠償**：上限があるか（例：受け取った報酬額まで）。1人会社は上限なしを避ける
- [ ] **契約不適合責任**：期間（例：検収から6か月）
- [ ] **再委託**：外注やAIツールの利用が禁止されていないか
- [ ] **解約**：予告期間、途中解約の精算
- [ ] **自動更新**：あるか、止めるにはいつまでに言うか
- [ ] **管轄裁判所**：自社の所在地から遠すぎないか
- [ ] **反社会的勢力の排除**条項

## 1人会社で特に注意

- 損害賠償の上限なし、競業禁止が広すぎる、成果物の権利がすべて相手に移る、の3つは修正を求める
- 金額が大きい・長期の契約は弁護士に見てもらう
