# 1人会社 AI運営環境

社員はオーナー1人。各部署の仕事はAI社員（Claude のエージェント）が担当し、オーナーは確認と決定だけを行う。

## 組織図

```
オーナー（社長：決定・承認・送信・支払）
 └ 秘書室 secretary ……… メール・予定の整理、仕事の振り分け
    ├ 経営企画部 strategy ……… 事業計画、数字、価格、調査
    ├ 営業・マーケ部 sales-marketing … 見込み客、提案書、営業メール、発信
    ├ 事業部 delivery ……… 商品・サービスの制作と納品
    ├ 経理部 accounting ……… 請求、記帳、入金確認、資金繰り
    ├ 総務・法務部 admin-legal … 契約、届出、期限管理
    └ 情報システム部 it-ops …… ツール、セキュリティ、自動化
```

## 頼み方の例

| こう言う | 動く部署 |
|---|---|
| 「今日やることをまとめて」 | 秘書室 |
| 「〇〇社に出す提案書を作って」 | 営業・マーケ部 |
| 「〇〇社に10万円で請求書を作って」 | 経理部 |
| 「この契約書を見て」（`inbox/` に置く） | 総務・法務部 |
| 「月20万円の利益を出すには何件必要？」 | 経営企画部 |
| 「週次レビューして」 | 全部署（`weekly-review`） |
| 「先月の月次締めをして」 | 経理部（`monthly-close`） |

## フォルダ

| 場所 | 中身 |
|---|---|
| `profile.md` | 会社の基本情報・事業内容・目標（**最初に埋める**） |
| `policies.md` | AIが自分でやってよいこと / オーナーの確認が必要なこと |
| `finance/` | 売上台帳 `sales.csv`、経費台帳 `expenses.csv`、請求書 `invoices/` |
| `sales/` | 案件管理 `pipeline.csv`、提案書 `proposals/` |
| `strategy/` | 事業計画、KPI `kpi.csv` |
| `admin/` | 期限カレンダー、契約管理、契約チェックリスト、アカウント管理表 |
| `templates/` | 請求書・メールのひな形 |
| `reports/` | 週次・月次レポート |
| `inbox/` | オーナーが渡す未整理の資料 |

## はじめにやること

1. `profile.md` の事業内容・目標を埋める（AIに「事業内容は〇〇」と伝えれば書き込む）
2. `.claude/agents/delivery.md` に事業の中身を書き足す
3. 週次レビュー・月次締めを定期実行にする（例：毎週月曜朝、毎月3日）
