# company/ — 会社スキルの案件置き場

`company` スキル（`.claude/skills/company/`）が、案件ごとのフォルダと記録をここに作る。
**この README 以外はコミットされない**（個人情報を含みうるため `.gitignore` で除外）。

```text
company/
├── <YYYY-MM-DD>_<案件名>/
│   ├── plan.md        計画（タスク・担当・モデル）
│   ├── progress.md    進捗ログ（一手ごとに追記。止まってもここから再開）
│   ├── state.json     使ったトークン・予算・タスクの状態
│   ├── T1_….md        各部署の成果物
│   ├── review_T1.md   品質管理部の検収
│   └── report.md      オーナーへの報告
├── DECISIONS.md       決裁待ち箱（オーナーの判断待ちをためる）
└── LOG.md             終わった案件の一覧（1案件1行）
```

クラウドのセッションは終了すると消えるので、残したい成果物はダウンロードするか、別の場所に保存する。
