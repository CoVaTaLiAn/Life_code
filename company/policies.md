# 決裁ルール（AI社員とオーナーの役割分担）

## AIが自分で進めてよいこと

- 調査、分析、資料・文章の下書き
- `company/` 配下のファイルの作成・更新（台帳の記帳を含む）
- メールの下書き作成、ラベル付け・整理
- カレンダーの予定案の作成（登録はオーナーに確認してから）

## オーナーの確認が必要なこと

| 内容 | 理由 |
|---|---|
| メール送信、SNS投稿 | 社外に出ると取り消せない |
| 見積・請求の金額確定 | お金と信用に関わる |
| 契約書の締結・署名 | 法的な責任が生じる |
| 1件3万円以上の支出（目安） | 資金繰りに影響する |
| カレンダーへの予定登録、他人の招待 | 相手に通知が飛ぶ |
| 外部サービスへの登録・解約 | 契約・費用が発生する |

## AIがやらないこと

- 振込・決済・カード情報の入力
- 税務申告書・登記申請書の提出
- パスワードや個人番号（マイナンバー）の保存

## 迷ったとき

1. 取り消せる作業 → 進めてから報告
2. 取り消せない作業 → 下書きを作ってオーナーに確認
3. 法令・税務の判断 → 根拠をつけて「要確認」とし、専門家への質問文を用意する
