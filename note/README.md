# Obsidian → note 有料記事を毎日出す

自分の苦悩を Obsidian で書いて、note に有料記事として毎日投稿するための手順と道具。

```
① Obsidian でテンプレートから書く（10〜30分）
② note_prep.py でチェック＆変換（10秒）
③ note に貼って、価格と有料ラインを決めて投稿（3分）
④ note_prep.py --done で「投稿済み」を記録
```

## 投稿を全自動にしない理由

note には記事投稿用の公式 API がありません。非公式の方法で自動投稿すると、規約違反でアカウント停止になるおそれがあり、売上も止まります。
そこで「書く・整える・チェックする」は自動にして、最後の「貼って投稿」だけは手で行います（3分ほど）。

---

## 最初に1回だけやること

### 1. このフォルダを Mac に置く
```bash
git clone https://github.com/CoVaTaLiAn/Life_code.git ~/Life_code
```

### 2. Obsidian にテンプレートを入れる
1. Vault に `Templates` フォルダと `note` フォルダを作る
2. `note/obsidian_templates/note記事.md` を Vault の `Templates/` にコピー
3. Obsidian の設定 → コアプラグイン → **テンプレート** をオン → テンプレートフォルダに `Templates` を指定
4. 設定 → ホットキー →「テンプレートを挿入」に好きなキー（例：⌘T）を割り当て

### 3. NGワードを登録する（任意・おすすめ）
実名や会社名がうっかり入るのを防ぎます。1行に1語。
```bash
nano ~/.note_ng_words.txt
```

### 4. note 側の準備
- note の「アカウント設定」→「お受け取り先」に振込先を登録する（売上の受け取りに必要）
- プロフィールに「何について毎日書くのか」を一文で書いておくと、フォローされやすい

### 5.（任意）Obsidian からボタン一つで変換する
コミュニティプラグイン **Shell commands** を入れて、次のコマンドを登録:
```bash
python3 ~/Life_code/note/scripts/note_prep.py {{file_path:absolute}} --copy
```
コマンドパレットから実行すると、今開いている記事がそのまま変換・コピーされます。

## 毎日やること

### ① 書く
1. Vault の `note` フォルダに新しいノートを作り、テンプレートを挿入
2. frontmatter の `title`・`price`・`tags` を埋める
3. `<!-- paywall -->` より上が **無料部分**、下が **有料部分**

書けない日は、走り書きを Claude に渡して「noteの記事にして」と頼めば、同じ形の下書きにします（`note-article` スキル）。

### ② チェック＆変換
```bash
python3 ~/Life_code/note/scripts/note_prep.py ~/Obsidian/note/2026-11-02.md --copy
```
- タイトル・価格・タグ・文字数と、**有料ラインを引く位置**が表示されます
- 無料部分が短すぎる、NGワードがある、画像がある…などは ⚠ で教えてくれます
- ブラウザでプレビューが開きます（本文が選択された状態なので、そのまま ⌘C でもコピー可）
- Obsidian 独自の書き方は自動で直ります

| Obsidian | note に貼るとき |
|---|---|
| `[[ページ名\|表示名]]` | 表示名だけ |
| `==強調==` | 太字 |
| `%%コメント%%`、`<!-- -->` | 消す |
| `> [!note]` コールアウト | 普通の引用 |
| `#タグ`（本文中） | 消す（タグは note 側で付ける） |
| `###` 以下の見出し | 小見出し（note は2段階まで） |
| 画像 | 外す（note で手動アップロード） |

### ③ note に投稿
1. note で「投稿」→「テキスト」
2. タイトル欄にタイトルを入力、本文に ⌘V
3. 画像があれば挿入（見出し画像もここで）
4. 「公開に進む」→ ハッシュタグを入れる
5. **「有料」を選び、価格を入力**
6. **「有料エリア設定」で、表示された段落の直後にラインを動かす**
7. 投稿

### ④ 投稿済みにする
```bash
python3 ~/Life_code/note/scripts/note_prep.py ~/Obsidian/note/2026-11-02.md --done https://note.com/あなたのID/n/xxxx
```
frontmatter が `status: published` になり、URL と日付が残ります。
Obsidian の Dataview プラグインを使えば、投稿一覧や連続投稿日数も出せます。

## 続けるコツ

- **値段は 100〜300円から**。最初はまとめ買いされる「マガジン」（月額や買い切り）にまとめると売りやすい
- **無料部分で「何があったか」、有料部分で「本音と気づき」**。無料部分だけで答えまで書かない
- 毎日が重い日は、無料記事の日を作ってもよい（`price: 0` にすると有料ラインのチェックを省きます）
- 他人が特定される書き方は避ける（家族・職場の人も読む前提で）
- しんどさが強いときは、書くより休むことを優先する

## ファイル

| ファイル | 中身 |
|---|---|
| `obsidian_templates/note記事.md` | Obsidian 用テンプレート |
| `scripts/note_prep.py` | チェック・変換・投稿済み記録（Python 3 のみ、追加インストール不要） |
| `../.claude/skills/note-article/SKILL.md` | 走り書き → 記事下書き（Claude 用） |
| `drafts/` | 下書き置き場（git には上げない） |
