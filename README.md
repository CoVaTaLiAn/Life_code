# solo-company-os

**1人会社を「AI社員」で運営するための仕組み一式。** 社員はオーナー1人。経理・営業・総務などの部署の仕事は Claude（Claude Code）のエージェントが担当し、オーナーは確認と決定だけをします。

```
オーナー（社長：決定・承認・送信・支払）
 └ 秘書室 ……………… 毎朝のまとめ、メール・予定の整理、振り分け
    ├ 経営企画部 ……… 事業計画、損益分岐点、価格、KPI
    ├ 営業・マーケ部 … 案件管理、提案書、営業メール、発信
    ├ 事業部 ………… 商品・サービスの制作と納品
    ├ 経理部 ………… 請求書、入金、経費、月次締め、資金繰り
    ├ 総務・法務部 …… 契約書、期限管理、議事録
    └ 情報システム部 … ツール、セキュリティ、自動化
```

## 何ができるか

| 頼み方（Claude に話しかける） | 中で起きること |
|---|---|
| 「今日やることは？」 | 予定・メール・未入金・期限から優先順位を5つに絞る |
| 「A社に業務支援40万円で請求書を作って」 | 請求書（Markdown＋印刷用HTML）を作り、売上台帳に記録 |
| 「A社から入金があった」 | 入金を記録。振込手数料の差額も記録 |
| 「カード明細を取り込んで」 | CSVを取り込み、勘定科目を自動で分類、重複はとばす |
| 「先月の月次締めをして」 | 損益、未入金、資金繰り、税理士への質問をまとめる |
| 「週次レビューして」 | 今週やること3つと数字を1枚に |
| 「次の期限は？」 | 設立日・決算月から届出・税金の期限を日付で出す（土日祝・年末年始も考慮） |
| 「単価30万円で月いくら売ればいい？」 | 損益分岐点と必要な作業時間を計算 |
| 「この契約書を見て」 | チェックリストで確認し、修正案を出す |

お金を動かす・メールを送る・契約や届出を出す、といった取り消せないことは **AIはしません**（下書きまで）。

## はじめかた

1. このリポジトリを **非公開（Private）** で持つ（会社のお金の記録が入るため）
2. Claude Code でこのリポジトリを開き、「**初期設定をして**」と話しかける（`onboarding`）
3. 質問に答えると、会社の設定・事業内容・固定費・期限カレンダーができる
4. 毎朝・毎週・毎月の定例を自動で回す → [docs/automation.md](docs/automation.md)

サンプル会社のデータで動きを見るなら：

```bash
./solo --root examples/demo --today 2026-10-30 report weekly
./solo --root examples/demo --today 2026-10-30 dashboard   # examples/demo/reports/dashboard.html
```

## フォルダ

| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | AI社員全員が守るルール |
| `.claude/agents/` | 部署ごとのAI社員の指示書 |
| `.claude/skills/` | 定例業務の手順（毎朝・週次・月次・決算・初期設定） |
| `company/` | **自社のデータ**（設定、台帳、契約、レポート、ひな形） |
| `tools/solo/` | 台帳・請求書・期限・レポートのツール本体（Python標準ライブラリのみ） |
| `examples/demo/` | サンプル会社のデータ |
| `docs/` | 使い方・データの形式・自動化・設立手続き |
| `tests/` | ツールのテスト |

## 注意

- 税金・社会保険・期限の計算は一般的なルールに基づく**目安**です（2026年10月時点）。申告・届出の前に、公式情報と税理士などの専門家で確認してください
- 台帳は税込の概算管理です。正式な帳簿・決算は会計ソフトと税理士で行う前提です
