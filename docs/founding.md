# 会社設立の手順（まだの人向け）

> 2026年10月時点の一般的な情報。費用・手続きは変わることがあるので、法務局・公証役場・国税庁などの公式情報で確認すること。

## 1. 会社の形を選ぶ

| | 合同会社 | 株式会社 |
|---|---|---|
| 設立の実費（目安） | 約6万円〜（登録免許税 6万円。紙の定款なら印紙4万円が加わる） | 約20万円〜（登録免許税 15万円、定款認証の手数料 1.5万〜5万円など） |
| 定款の認証 | 不要 | 公証役場で必要 |
| 役員の任期 | なし | あり（非公開会社は最長10年）。満了ごとに登記 |
| 決算公告 | 不要 | 必要 |
| 信用・見え方 | 取引先によっては株式会社を好む | 一般的 |
| 向いている人 | 費用と手間を抑えたい、BtoC や個人向け中心 | 大企業との取引、将来の出資の受け入れ |

- 登録免許税は「資本金×0.7%」と上の額の高いほう
- 株式会社の定款認証の手数料は資本金の額などで変わる（一定の要件を満たす小規模な会社は1.5万円に下がる制度がある。要確認）
- 電子定款にすると印紙代4万円がかからない

## 2. 決めること

- 商号（会社名）、本店所在地（自宅でもよいが賃貸の契約を確認）
- 事業の目的（将来やりそうなことも入れる。許認可が必要な事業は書き方に注意）
- 資本金（1,000万円未満にすると、原則として設立後2期は消費税の免税事業者になれる。ただし特定期間の判定に注意）
- 決算月（設立月の前月にすると1期目が最も長い。繁忙期を避ける）
- 役員（1人会社なら自分だけ）

## 3. 設立の流れ

1. 会社の実印を作る
2. 定款を作る（会社設立サービスや司法書士を使うと電子定款にしやすい）
3. （株式会社のみ）公証役場で定款の認証
4. 資本金を自分の個人口座に振り込み、通帳の写しを取る
5. 法務局に登記申請（**申請した日が設立日**）
6. 1〜2週間で登記完了 → 登記事項証明書・印鑑証明書を取る

## 4. 設立後

- 届出：`./solo deadlines --save` で期限つきの一覧が出る（年金事務所・税務署・自治体）
- e-Gov の「法人設立ワンストップサービス」を使うと、税務署・自治体・年金事務所への届出をまとめて出せる
- 法人口座の開設（審査に1〜4週間かかることがある）
- 会計ソフト、税理士の選定
- 役員報酬を決める（設立から3か月以内。`company/templates/minutes/officer-compensation.md`）
- このリポジトリで「初期設定をして」と頼み、`company/config.toml` を本番の値にする

## 5. 専門家の使い分け

| 専門家 | 頼むこと |
|---|---|
| 司法書士 | 登記（設立、役員変更、本店移転） |
| 税理士 | 決算・申告、税務の相談。法人は顧問を付けるのが一般的 |
| 社労士 | 社会保険・労働保険（人を雇ったとき） |
| 行政書士 | 許認可の申請 |
| 弁護士 | 契約書の確認、トラブル |
