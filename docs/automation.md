# 定例業務の自動化

Claude Code の「スケジュール実行（scheduled tasks）」を使うと、決まった時間にAI社員が動きます。
このリポジトリを選んだ Claude Code のセッションで、下の文をそのまま頼めば設定できます。

## おすすめの3つ

| いつ | 頼む文 |
|---|---|
| 平日の朝 | 「平日の毎朝 7:40 に daily-brief スキルで朝のまとめをして、結果を通知して」 |
| 毎週月曜 | 「毎週月曜 8:10 に weekly-review スキルで週次経営会議をして、レポートを保存して」 |
| 毎月3日 | 「毎月3日 9:20 に monthly-close スキルで先月の月次締めをして、確認してほしいことを教えて」 |

時刻を「ちょうど0分」から少しずらしておくと、混雑で遅れにくくなります。

## 動かす前に確認すること

- Gmail・Googleカレンダーをつないでおく（claude.ai の「コネクタ」設定）。つながっていない場合、メールと予定の部分はとばしてレポートが作られる
- 自動実行で作ったレポートやデータの変更は、コミットして残す（「終わったらコミットしてプッシュして」と頼みに含める）
- 自動実行でも、メール送信・支払い・届出はしない（`CLAUDE.md` のルール）

## 決算月の前後

決算は年1回なので自動にせず、決算月の1か月前に「決算の準備をして」（`year-end-close`）と頼むのがおすすめです。
`./solo deadlines --ics` で作ったカレンダーに決算の期限が入るので、それを合図にしてください。

## GitHub Actions（テスト）

`.github/workflows/ci.yml` で、プッシュのたびにツールのテストと、サンプルデータの点検が動きます。
自社データ（`company/`）の点検も通すので、CSVの形が崩れたときに気づけます。
