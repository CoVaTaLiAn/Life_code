# House Prices 改善レポート

## 結論
| | 手元 CV（対数 RMSE, 5-fold×3回平均） |
|---|---|
| v1（最初に提出: Lasso + LightGBM） | 0.1091 |
| **v3（最終: 4モデル均等ブレンド）** | **0.1056** |

約 3% の誤差削減。Kaggle の公開スコアはこの環境から見られないため、すべて手元の CV で判断した。

## やったこと（データサイエンティストとしての手順）

### 1. 評価の土台を作り直す
- 5分割 × 3回（分け方を変えて）繰り返す CV にして、たまたまの当たり外れを減らした。全実験で同じ分け方を使い、差を公平に比べられるようにした。
- 全実験の結果・予測を保存（`exp/results_snapshot.jsonl`, `exp/cache/`）し、あとで組み合わせ検証に再利用した。
- モデルの重みを決めるときも「重みを決めるデータ」と「評価するデータ」を分ける二段階 CV にし、自分をだまさないようにした。

### 2. 誤差分析
- 外し方の大きい上位10件が誤差全体の 21% を占めていた。中身は「訳あり売却（Abnorml / Family）」が中心で、家の特徴からは予測できない取引。
- → 学習時にこれらを除外する案を試したが **悪化**（0.1108 → 0.1114〜0.1118）。除外しないのが正解と判断。

### 3. 特徴量エンジニアリング（Lasso で一つずつ効果を測定）
| 追加したもの | CV |
|---|---|
| ベースライン | 0.1118 |
| 順序のあるカテゴリを数値化（地下の採光、仕上げ等級など10列） | 0.1116 |
| 交互作用・フラグ（品質×面積、品質²、築浅フラグ、部屋あたり面積など15個） | 0.1112 |
| ガレージ築年の欠損と誤記（2207年）を修正 | 0.1116 |
| **上の3つ全部** | **0.1108** |
| 地区内での相対値（同じ地区の中央値との差） | Lasso 改善・SVR 悪化 → 不採用 |
| 主要変数の2乗項 / 築年代ダミー | 誤差の範囲 → 不採用 |

### 4. モデル変更
- 線形系（Lasso / ElasticNet / Ridge / SVR / カーネルリッジ）と木系（LightGBM / XGBoost / CatBoost / sklearn GBR）を同じ特徴量で比較。
- このデータは件数が少なく（1458件）価格と面積の関係がほぼ直線なので、**線形系の方が木系より強い**。
- SVR はパラメータ調整で 0.1109 → 0.1097。

### 5. 一番効いた工夫：線形モデル → 木で残差補正（2段モデル）
- Lasso で大まかな価格を出し、Lasso が外した分（残差）だけを木モデルに学習させる。線形の「面積に比例」と、木の「条件の組み合わせ」の良いとこ取り。
- Lasso 単体 0.1108 → **Lasso + GBR 0.1067**（単体モデルで最良）。
- 乱数シード3つの平均でさらに安定（0.1066）。

### 6. アンサンブル
- 重みを最適化したブレンドより **均等重みの方が良かった**（最適化は検証データに合わせすぎる）。
- 候補を足し引きしても 0.1056〜0.1059 で差は誤差の範囲 → 一番シンプルな4モデルを採用。

## 試してダメだったこと（これも成果）
- 外れ値の学習時除外、Huber 回帰（0.127）、木モデルに「面積あたり価格」を予測させる、地区内相対特徴量の一律追加。

## 注意
- 公開リーダーボードのスコアは CV と完全には一致しない（テストの半分だけで計算されるため）。CV 0.001 程度の差は LB では逆転しうる。
- House Prices は練習用コンペでメダルは出ない。この進め方（CV の土台 → 誤差分析 → 特徴量を一つずつ検証 → 多様なモデル → 素直なアンサンブル）はメダル対象コンペでもそのまま使える。
