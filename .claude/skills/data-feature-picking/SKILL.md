# 特徴量候補のピックアップ（選んで報告するだけ。作らない）

**この処理は候補を選ぶだけ**を行う。入力はクレンジング後の `cleaned.csv`。目的変数（数値か 0/1）があると見られる範囲が広がる。
`D=analysis/<YYYY-MM-DD>_<名前>`

## 実行
```bash
python3 .claude/skills/data-feature-picking/scripts/pick_features.py \
  --input $D/02_cleanse/cleaned.csv --out $D/08_features [--target <目的変数>] \
  [--columns 列,列] [--values 列,列] [--min-count 20] [--perm 500]
```
必要なのは pandas と numpy だけ。

## 見るものと、そこから出る候補
| 記号 | 見るもの | 候補になる特徴量 | 目的変数 |
|---|---|---|---|
| A | カテゴリ列によって目的変数が違うか | その列そのもの（One-Hot・順序・ターゲット） | 必要 |
| B | 全体と明らかに違う個別のカテゴリ（差が標準誤差の 2.5 倍以上） | `列=値` のフラグ | 必要 |
| C | カテゴリ列によって数値列の水準が違うか | 数値 ÷ カテゴリ別の中央値（カテゴリ内での相対値） | 不要 |
| D | 2つのカテゴリ列を掛け合わせると初めて見える差 | 組み合わせカテゴリ | 必要 |
| E | 欠損かどうかで目的変数が違うか | 欠損フラグ | 必要 |

評価は、η²（相関比。グループ数で補正）と並べ替え検定の p。優先度は **高** = η² ≥ 0.06 かつ p < 0.01、**中** = η² ≥ 0.01 かつ p < 0.05、それ以外は見送り。
件数が `--min-count` 未満のカテゴリは「その他」にまとめ、個別には評価しない。

## 出力
| ファイル | 内容 |
|---|---|
| `report.md` / `report.html` | ピックアップした候補（優先度・作り方・根拠）、A〜E の詳細、見送ったもの、使うときの注意 |
| `feature_candidates.csv` / `.json` | 候補の一覧（見送りも含む） |

## 確認して渡す
- 候補を課題の意味で読み直す。**予測時点で分からない情報から作る候補（リーク）は外す**。意味の説明がつかない組み合わせは「偶然の可能性」と明記する（多くの組を調べるので、p が 0.05 に近い候補は偶然でも出る）
- `data-visualizing` の図があれば、候補に挙がった列の図（`figs/<列名>.png`）で数字を目で確かめる
- `report.html` を SendUserFile で送る
- 返答には、優先度の高い順に候補・作り方・根拠の数字を書き、偶然かもしれないものはそう書く
- 採用した候補を実際に作って効果を確かめるのは次の工程（モデルに入れて交差検証）。この処理ではやらない
- 見本: `analysis/example_dataprep_sample/08_features/report.md`
