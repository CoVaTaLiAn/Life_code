# 朝のまとめ

秘書室（secretary）の手順。5分で読める長さにする。

## 手順

1. **予定**：Googleカレンダーで今日と明日の予定を見る。準備が必要なもの（資料、移動、事前に読むもの）に印をつける
2. **メール**：Gmail で直近24時間（月曜は72時間）の受信を見る
   - 要返信：返信の下書きを作る（送信はしない）。下書きの件名を一覧にする
   - 要対応：請求・入金・契約・期限つきの連絡。担当部署を書く
   - 入金の連絡があれば、経理部に `./solo invoice paid` を頼む（オーナー確認後）
3. **会社の状況**：`./solo report weekly` を実行し、次を拾う
   - 期限超過の未入金
   - 次の行動日が過ぎた案件
   - 14日以内の期限
4. **今日やること**：上の結果から最大5つ。締切があるもの → お金に関わるもの → 営業 → その他、の順
5. スマホで読める形で報告する（ファイルには保存しない）

## 報告の形

```
☀ 今日やること
1. …（〇〇部 / 期限：今日）
📅 予定：10:00 〇〇社打合せ（資料：…）
✉ 下書きを作った返信：3件（件名…）
⚠ 期限が近いもの：…
```
