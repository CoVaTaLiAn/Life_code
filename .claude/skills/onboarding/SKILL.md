# 初期設定

一度に全部聞かず、3〜5問ずつ聞いて埋めていく。分からない項目は仮の値を置き「（仮）」と書いて先に進む。

## 1. 会社の基本（`company/config.toml` の [company] と `company/profile.md`）

- 商号、会社の形（株式会社 / 合同会社）、代表者名
- 設立日、決算月（決めていなければ「設立月の前月」を勧める：1期目が最も長くなる）
- 本店所在地、連絡先メール・電話

## 2. 事業（`company/profile.md` の事業内容、`.claude/agents/delivery.md`）

- 何を、誰に、いくらで、どう届けるか
- 1件あたりの作業時間の目安、外注するか
- 強み・他社との違い
- delivery.md の「提供するもの」「作業手順」「品質基準」を書く

## 3. お金（`company/config.toml` の [invoice] [tax] [cash] [goal]、`company/finance/recurring.csv`）

- インボイス登録の有無と登録番号、支払期限のルール（翌月末 / 30日後）、振込先
- 課税事業者かどうか（分からなければ false のままにし、税理士に確認と書く）
- 今の口座残高と基準日
- 毎月の固定費：役員報酬、社会保険料、家賃、ツール代など → recurring.csv
- 月の売上・利益の目標

## 4. 仕上げ

1. `./solo check` でエラーがないことを確認
2. `./solo deadlines --save` で期限カレンダーを作り、`./solo deadlines --ics company/reports/deadlines.ics` でカレンダー用ファイルを作る
3. 価格が決まっていれば `./solo breakeven --price 単価 --hours 時間` で必要件数を示す
4. `./solo dashboard` を作る
5. オーナーに「埋めた項目」「仮のままの項目」「次にやること（最大3つ）」を報告する
