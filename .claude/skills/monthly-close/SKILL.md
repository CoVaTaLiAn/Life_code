# 月次締め

経理部（accounting）の手順。対象は前月1か月分。

## 手順

1. **記帳もれの確認**
   - Gmail で前月の「請求書」「領収書」「ご利用明細」「receipt」「invoice」を検索し、`company/finance/expenses.csv` と `sales.csv` にない取引を一覧にする
   - 見つかったものは台帳に追加し、勘定科目に迷うものは「要確認」と書く
2. **売上と入金**
   - 前月に納品した案件（`company/sales/pipeline.csv` の受注）で請求していないものを探す
   - 入金予定日を過ぎた未入金を一覧にし、催促メールの下書きを作る（送信はしない）
3. **損益**：python で前月と年初からの累計の売上・経費（勘定科目別）・利益を計算する
4. **資金繰り**：今後3か月の入金予定と支払予定（役員報酬、社会保険料、家賃、税金の予定）から月末残高の見通しを出す
5. **KPI**：`company/strategy/kpi.csv` に前月の行を追加する
6. **税理士への資料**：台帳、証憑の一覧、要確認の取引と質問をまとめる
7. `company/reports/YYYY-MM_monthly.md` に保存する

## レポートの形

```
# 月次締め YYYY年MM月
## 結論（売上・利益・手元資金を1行ずつ）
## 損益（前月 / 累計）
## 未請求・未入金
## 資金繰り（3か月）
## 要確認の取引（税理士への質問）
## 記帳もれとして追加したもの
```

金額は概算と明記し、お金の移動はしない。
