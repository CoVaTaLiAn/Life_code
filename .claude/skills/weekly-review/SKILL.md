# 週次経営会議

各部署の情報を集め、オーナーが5分で読める1枚にまとめる。

## 手順

1. `company/profile.md` と `company/policies.md` を読む
2. **数字（経理部）**：`company/finance/sales.csv` と `expenses.csv` から、今月の売上・経費・利益（累計）と未入金を出す。計算は python で行う
3. **案件（営業部）**：`company/sales/pipeline.csv` から、段階ごとの件数と見込金額、次の行動日が過ぎている案件を出す
4. **期限（総務部）**：`company/admin/deadlines.md` と `contracts.csv`（解約予告期限）から、14日以内のものを出す
5. **予定（秘書室）**：Googleカレンダーで今週の予定を確認する
6. **目標との差（経営企画部）**：`company/profile.md` のKPIと比べ、足りない分を埋める行動を考える
7. `company/reports/YYYY-MM-DD_weekly.md` に保存する

## レポートの形

```
# 週次経営会議 YYYY-MM-DD
## 結論（今週やる3つ）
## 数字：今月の売上 / 経費 / 利益 / 未入金
## 案件：段階ごとの件数と金額、止まっている案件
## 期限：14日以内
## 先週からの変化・気になること
```

データが空のときは「まだ記録なし」と書き、何を記録すればよいかを1行で示す。
