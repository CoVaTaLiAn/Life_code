# 週次経営会議

オーナーが5分で読める1枚にまとめる。数字は `./solo` で出し、手計算しない。

## 手順

1. `company/profile.md` と `company/policies.md` を読む
2. `./solo check` で台帳の点検。エラーがあれば先に直す（直せないものはレポートに書く）
3. `./solo report weekly --save` を実行する（数字・未入金・案件・期限・契約が入った下書きができる）
4. Googleカレンダーで今週の予定を確認し、営業や制作に使える時間がどれくらいあるかを見る
5. 下書きに次を書き足す
   - **今週やること（最大3つ）**：未入金の催促、止まっている案件の次の一手、期限、の順で優先
   - **営業**：今週接触する見込み客（`./solo deals --stale` と `company/sales/pipeline.csv`）
   - **気になること**：売上の1社依存、手元資金の減少、作業時間の不足など
6. `./solo dashboard` でダッシュボードを更新する
7. 保存した `company/reports/YYYY-MM-DD_weekly.md` の要点を、スマホで読める長さでオーナーに報告する

## 報告の形

```
今週やること
1. …
2. …
3. …
数字：今月の売上 / 利益 / 未入金（期限超過）/ 3か月後の手元資金
気になること：…
```

データが空のときは「まだ記録なし」と書き、何を記録すればよいかを1行で示す。
