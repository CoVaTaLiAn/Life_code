# Gmail の判断待ちを片付ける

GAS（`gas/gmail-sorter/Code.gs`）が迷ったメールは、スプレッドシート「Gmail振り分けログ」のシート「判断待ち」に1行ずつ載っている。
Claude は提案を書くだけで、決めるのはユーザー。決定を「あなたの判断」列に書けば、GAS が1時間以内に処理し、その送信元を覚える。

**トークン節約が最優先**。シートの行（差出人・件名・冒頭100字・確率）だけで判断し、Gmail の本文は開かない。
行の情報だけでどうしても決められないものに限り、`mcp__Gmail__get_thread` でその1通だけ読む。

## 手順

1. `mcp__Google_Drive__search_files` で「Gmail振り分けログ」を探し、スプレッドシートの ID を得る
   - Gmail ごとに1つある（サブのアカウントのものは「Gmail振り分けログ（アドレス）」で、共有されている）。**見つかったものすべて**を順に処理し、ユーザーにはアカウントごとに分けて見せる
   - 「判断待ち」シートがまだないシートは「判断待ちなし」として飛ばす
   - サブのアカウントのメールは Claude の Gmail 接続では読めない。決定は必ずシートの K 列に書く
2. `mcp__Google_Sheets__get_values` で `判断待ち!A:L` を読む
   - 列：A ID / B 受信日時 / C 差出人 / D 件名 / E 冒頭 / F スパム確率 / G 既読でよい確率 / H 確率の出どころ / I Claudeの提案 / J Claudeの理由 / K あなたの判断 / L 処理済み
   - 対象は **K と L が空の行**だけ。0件なら「判断待ちはありません」と伝えて終わる
3. 各行に提案を1つ選ぶ。選べる値は3つだけ（この表記のまま書く）：`既読` `残す` `迷惑メール`
   - `既読`：ただの通知・宣伝・メルマガ・イベント案内・条件に合わない求人・領収書
   - `残す`：人からの連絡、面談・予約・手続き・支払い・アカウント関係、条件に合う求人（判断基準は `Code.gs` の `CONFIG.profile`）
   - `迷惑メール`：詐欺・フィッシング・出会い系・怪しい儲け話。確率F が高くても、知っている会社や人からなら疑う
   - 決定は送信元ごとに覚えられる。同じ送信元から大事なメールも来そうなら `残す` を勧め、その旨を理由に書く
4. `mcp__Google_Sheets__update_values` で I 列（提案）と J 列（理由・20字以内）を**まとめて1回で**書く
5. ユーザーに短い表で見せる：番号・差出人・件名・確率（スパム／既読）・提案・理由
   最後に「提案どおりでよければ『全部OK』、変えるものは『3は残す』のように」と聞く
6. ユーザーの答えを K 列（あなたの判断）に**まとめて1回で**書く。ユーザーが決めていない行は K を空のままにする
   - K は GAS が入力規則を付けた選択式。上の値以外は書かない
7. 「1時間以内に GAS が処理し、同じ送信元は次から自動で振り分けます」と伝えて終わる

## やらないこと

- ユーザーの確認なしに K 列を書かない（提案は I 列だけ）
- Gmail の既読・削除・迷惑メール報告を Claude から直接しない（処理と学習は GAS に任せる）
- 「判断待ち」シートがまだなく、メインのアカウントの Gmail に「要判断」ラベルのメールがある場合だけ、
  ユーザーが決めたあとに `mcp__Gmail__label_thread` で「既読」か「残す」のラベルを付けてよい（GAS がそれを読んで処理・学習する）
- 処理済み（L が埋まっている）行は触らない
