# 決算準備

経理部と総務・法務部の共同作業。正式な決算書・申告書は税理士が作る前提で、その材料をそろえる。

## 決算月の1か月前

1. `./solo deadlines --from 今日 --to 決算日から3か月後` で、申告・納付・定時総会の期限を確認する
2. 利益の見込みを出す：`./solo report monthly` を期首から並べ、残り月の見込みを足す（経営企画部）
3. 利益が大きく出そうなら、税理士に相談する項目を洗い出す（必要な設備の購入時期、役員報酬は期中に変えられない点など）。**節税目的だけの支出は勧めない**

## 決算日のあと

1. **台帳の点検**：`./solo check` のエラー0件、「要確認」の科目をすべて解消（税理士に聞くものは質問にする）
2. **売掛金**：`./solo invoice list --unpaid` で決算日時点の未入金を一覧にする
3. **未払い**：決算月に使ったが支払いが翌月以降のもの（カード、社会保険料など）を一覧にする
4. **資産になる買い物**：10万円以上の物品を一覧にする（`./solo check` の注意に出る）
5. **在庫・前受金**があれば一覧にする
6. **通帳の残高**：決算日の残高（証明書や画面の写し）
7. `company/reports/YYYY_year-end_for-accountant.md` にまとめる：上の一覧、台帳の場所、証憑の保管場所、質問

## 申告まで

1. 税理士から決算書が届いたら、`company/templates/minutes/annual-meeting.md` で定時総会（社員総会）の議事録を作る
2. 株式会社は決算公告の段取り（官報・電子公告など）を確認する
3. 納付額と期限を資金繰りに入れる（`company/finance/recurring.csv` に年払いとして追加するか、オーナーに伝える）
4. 翌期の役員報酬を決める場合は、期首から3か月以内に議事録を作る（`company/templates/minutes/officer-compensation.md`）
