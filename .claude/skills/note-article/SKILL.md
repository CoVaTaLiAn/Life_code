# note 有料記事の下書きづくり

ユーザーの走り書き（箇条書き・愚痴・断片でよい）を、Obsidian テンプレート
`note/obsidian_templates/note記事.md` と同じ形の Markdown にする。

## 守ること
- **本人の言葉を残す**。きれいに言い換えすぎない。口調・言い回しはメモに合わせる
- 書いていない出来事や感情を**足さない**。足りないところは最後に質問として返す
- 実名・会社名・学校名・地名など、本人や他人が特定される情報は伏せる（例：「上司のAさん」）
- 自傷・希死念慮が書かれていたら、記事化より先に体調を気づかい、相談先（いのちの電話 0570-783-556、よりそいホットライン 0120-279-338）を伝える

## 形
1. frontmatter：`title`（32字以内、具体的な場面＋感情。例「朝起きられない自分を責めた日」）、`price`（既定 300）、`tags`（3〜5個）、`status: draft`、`date`
2. 無料部分（300〜800字）：何があったか・何がしんどかったか。読者が「自分もそう」と思える所まで
3. `<!-- paywall -->`
4. 有料部分（800字〜）：本音、具体的なやりとりや数字、そこからの気づき、同じ悩みの人へ一言
   - 無料部分で「答え」を出し切らない。有料部分に読む理由を残す
5. 見出しは `##` と `###` だけ（note は2段階まで）

## 出力
- ファイルの指定があればそこへ書く。なければチャットに Markdown で返す
- **このリポジトリには下書きを保存・commit しない**（個人的な内容のため）。`note/drafts/` は .gitignore 済み
- 最後に「確認したいこと」を最大3つ
- 仕上げの確認は `python3 note/scripts/note_prep.py <ファイル>` で行える
