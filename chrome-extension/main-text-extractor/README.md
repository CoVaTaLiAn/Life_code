# 本文だけ抜き出し（Chrome 拡張機能）

表示中のページから **本文だけ** を取り出して、テキストまたは Markdown でコピー・保存する拡張機能。
メニュー・サイドバー・広告・シェアボタン・コメント欄などは取り除く。Markdown は Obsidian にそのまま貼れる形（タイトル・URL・取得日を front matter に入れる）。

## インストール（自分用・ストア公開なし）

1. このフォルダ（`chrome-extension/main-text-extractor`）を PC に置く
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選ぶ
5. ツールバーのパズルアイコンからピン留めしておくと便利

## 使い方

- 記事ページでアイコンをクリック（またはショートカット **Alt+Shift+E**）
- 「テキスト / Markdown」を選んで「コピー」か「ファイルに保存」
- ローカルの HTML ファイルで使う場合は、拡張機能の「詳細」で「ファイルの URL へのアクセスを許可する」をオンにする

## セキュリティの考え方

| 対策 | 内容 |
|---|---|
| 権限は 2 つだけ | `activeTab`（アイコンを押したタブだけ一時的に読める）と `scripting`（そのタブに抽出処理を入れる）。`<all_urls>` やホスト権限、`tabs`・`storage`・`history`・`cookies` などは要求しない。インストール時に「すべてのサイトのデータの読み取り」の警告が出ない |
| 勝手に動かない | 常駐スクリプト（content_scripts）もバックグラウンド処理もない。アイコンを押したときだけ、そのタブでだけ動く |
| 外部通信なし | `fetch` 等は使っていない。さらに CSP で `default-src 'none'` にしているので、仮にコードが混入しても外へ送れない |
| 外部コードを読まない | ライブラリも CDN も使わない。すべてのコードがこのフォルダ内にあり、読める量（約 400 行） |
| ページの HTML を実行しない | 抽出結果は **文字列だけ** をポップアップに返し、`textarea.value` / `textContent` で表示する。`innerHTML` は使っていないので、悪意のあるページでも拡張機能側でスクリプトが動かない |
| ページから干渉されない | 抽出処理は ISOLATED world（ページの JS とは別の実行環境）で動く。ページの DOM は読むだけで書き換えない |
| 隠し文字を拾わない | `display:none`・透明・画面外・`aria-hidden` の要素は無視する。AI に貼るときの「隠しプロンプト」対策にもなる |
| 危険なリンクを残さない | Markdown のリンクは `http` / `https` だけ。`javascript:` や `data:` の URL は出力しない |
| 余計な情報を残さない | URL から `utm_*`・`fbclid`・`gclid` などの計測用パラメータと `#` 以降を除く。何も保存しない（履歴も残さない） |
| iframe は読まない | メインのページだけを対象にし、埋め込み広告などのフレームには入らない |
| 大きすぎるページ対策 | 30 万文字・5 万ノードで打ち切り、ブラウザが固まらないようにする |
| 戻り値を検証 | ポップアップ側でも型と長さを確認してから使う。ファイル名から使えない文字・制御文字を除く |

### 注意

- 抜き出した文章自体はページ作成者が書いたもの。AI に貼る・人に共有するときは、中身が信用できるかは別途判断する
- ログインが必要なページ（社内システム・メール等）でも動くが、そのぶん機密情報をコピーしやすくなるので貼り先に注意
- 本文の判定はヒューリスティック（段落の長さ・句読点・リンクの多さで点数付け）。サイトによっては余分な部分が混ざったり、足りなかったりする

## ファイル構成

```
manifest.json   拡張機能の設定（権限・CSP・ショートカット）
extractor.js    ページに入れる本文抽出処理（文字列だけ返す）
popup.html/css/js  ボタンを押したときの画面
icons/          アイコン
test/           動作確認用（fixture.html と run-test.js）
```

## テスト

Playwright が入っている環境で:

```bash
node test/run-test.js
```

テスト用ページ（`test/fixture.html`）で、本文を取れること・メニュー/広告/隠し文字/スクリプトが入らないこと・`javascript:` リンクが消えること・拡張機能として読み込めて CSP 違反がないことを確認する。
